# Single-Page CV

A simple, semantic HTML CV project built as part of the [Roadmap.sh Single-Page CV challenge](https://roadmap.sh/projects/single-page-cv).

## About the Project

This project demonstrates how to structure a Curriculum Vitae using HTML, with a focus on semantic markup, SEO metadata, and social media sharing.

## Features

- Semantic HTML structure
- SEO meta tags
- Open Graph (OG) metadata
- Custom favicon
- Sections for skills, education, and career history
- HTML structure ready for future CSS styling

## Technologies Used

- HTML5
- Git
- GitHub

## How to Run the Project

1. Clone the repository:

   ```bash
   git clone https://github.com/BTCPL4YER/single-page-cv.git
   ```

2. Navigate to the project directory:

   ```bash
   cd single-page-cv
   ```

3. Open `index.html` directly in your browser, or use the Live Server extension in Visual Studio Code.
